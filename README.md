❤️ **Heart Disease Prediction Project**
📌 Project Overview

This project focuses on building a Heart Disease Prediction System using various classification algorithms in Machine Learning. The objective is to analyze medical attributes of patients and accurately predict whether a person is likely to suffer from heart disease or not.

Heart disease is one of the leading causes of death globally, and early prediction using data-driven models can help in timely diagnosis and treatment.

📊 **Dataset Description**

The dataset used in this project is derived from the Heart Disease Dataset (Cleveland Database), which is widely used for machine learning research and educational purposes.
**[Link](https://www.kaggle.com/datasets/arezaei81/heartcsv)**
Total Records: 303–304 patients

Number of Features: 14 selected attributes (from a total of 76 available)

Target Variable: Presence of heart disease

Target Values:

0 → No heart disease

1, 2, 3, 4 → Presence of heart disease (different severity levels)

⚠️ **Privacy Protection: Patient names and social security numbers were removed to ensure data privacy and ethical usage.**

🧾 Key Features in the Dataset
Feature	Description
age	Age of the patient (in years)
sex	Gender (1 = Male, 0 = Female)
cp	Chest pain type
trestbps	Resting blood pressure
chol	Serum cholesterol
fbs	Fasting blood sugar
restecg	Resting ECG results
thalach	Maximum heart rate achieved
exang	Exercise induced angina
oldpeak	ST depression
slope	Slope of the peak exercise ST segment
ca	Number of major vessels
thal	Thalassemia type
target	Heart disease presence


🫀 **Chest Pain (cp) Description**

The cp feature represents four types of chest pain:

Value	Type	Meaning
0	Typical Angina	Chest pain caused by reduced blood flow to the heart
1	Atypical Angina	Chest pain not directly related to the heart
2	Non-anginal Pain	Chest pain not related to heart conditions
3	Asymptomatic	No visible symptoms but disease may be present
🛠️** Machine Learning Models Used**

This project applies and compares multiple classification algorithms, including:

✅ Logistic Regression

✅ Support Vector Machine (SVM)

✅ Decision Tree Classifier

✅ Random Forest Classifier

✅ K-Nearest Neighbors (KNN)

The models are evaluated using:

Accuracy Score

Confusion Matrix

Precision, Recall, F1-Score


🎯 **Project Objective**

The main goals of this project are:

To understand how medical data can be used in predictive analytics

To compare different classification algorithms

To build a reliable heart disease prediction model

To gain practical experience in:

Data preprocessing

Feature selection

Model training

Model evaluation

This Heart Disease Prediction project demonstrates how Machine Learning can be effectively used in the healthcare domain for disease prediction.
